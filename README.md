# 🔧 OptiSkill - Simulador de Tallado de Lentes

Una aplicación web interactiva y gamificada para aprender y practicar técnicas de tallado de lentes ópticas.

## ✨ Características

- 🎮 4 Niveles de dificultad progresiva
- 💎 Sistema de puntos y rachas
- 🏆 6 Logros para desbloquear
- 💾 Guarda automáticamente tu progreso
- 🎨 Interfaz futurista con animaciones
- 📱 Totalmente responsivo

## 🚀 Cómo Usar

1. Abre `index.html` en tu navegador
2. Ingresa tu nombre
3. ¡Comienza a tallar lentes!

## 📊 Niveles

| Nivel | Material | Puntos | Dificultad |
|-------|----------|--------|-----------|
| 1 | CR-39 | 50 | Fácil |
| 2 | Policarbonato | 100 | Medio |
| 3 | Trivex | 150 | Difícil |
| 4 | Vidrio Óptico | 250 | Experto |

## 🏅 Logros

- 🎯 Primera Lente
- ✨ Maestro CR-39
- 🔥 Racha de 5
- 💎 500 Puntos
- 👑 Maestro Absoluto
- ⭐ Lente Perfecta
